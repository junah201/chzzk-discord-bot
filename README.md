# 치직

<img width="1344" height="756" alt="치직 대시보드 화면" src="https://github.com/user-attachments/assets/49947c4d-8e7e-4704-b8ba-431398cf0620" />

**치직**은 [치지직(CHZZK)](https://chzzk.naver.com) 스트리머가 방송을 켜면 디스코드 서버에 알림을 보내 주는 봇입니다.

스트리머 본인도, 팬 서버 운영자도 쓸 수 있습니다. 봇을 초대하고 치지직 채널을 등록하면, 방송이 켜질 때마다 원하는 디스코드 채널에 알림이 갑니다.

- **대시보드**: [chzzk.junah.dev](https://chzzk.junah.dev)
- **문서**: [chzzk.junah.dev/docs](https://chzzk.junah.dev/docs)
- **서포트 서버**: [chzzk.junah.dev/support-server](https://chzzk.junah.dev/support-server)

## 🚀 주요 기능

### 기본 기능 (무료)

* **방송 알림**: 방송이 켜지면 5분 안에 디스코드 채널로 알림이 갑니다.
* **웹 대시보드**: 디스코드 계정으로 로그인해 알림을 추가·수정·삭제하고, 테스트 알림을 보낼 수 있습니다.
* **메시지 꾸미기**: 알림 메시지에 멘션(@everyone, @here, 특정 유저·역할)과 디스코드 마크다운을 쓸 수 있습니다.
* **표시 설정**: 알림마다 임베드, 방송 태그, 바로가기 버튼을 숨기거나 알림을 잠시 멈출 수 있습니다.
* **여러 채널 등록**: 한 서버에서 여러 치지직 채널을 각각 다른 디스코드 채널로 받을 수 있습니다. (무료 슬롯 5개)

### 구독자 전용 기능 (월 정기 구독)

* **커스텀 웹훅**: 치직 봇 대신 원하는 **이름과 프로필 이미지**로 알림을 보냅니다. 디스코드 채널마다 웹훅을 따로 정할 수 있습니다. ([사용법](https://chzzk.junah.dev/docs/custom-webhook))
* **임베드 색상 변경**: 알림 임베드 색상을 서버 분위기에 맞게 바꿀 수 있습니다.
* **슬롯 250개**: 큰 서버도 알림을 넉넉하게 등록할 수 있습니다.
* **고급 필터링** *(지원 예정)*: 조건에 맞는 방송만 골라 알림을 받는 기능을 준비하고 있습니다.

> [!NOTE]
> 구독이 끝나도 웹훅 등 설정은 지워지지 않습니다. 구독하지 않는 동안에는 기본 치직 봇으로 알림이 갑니다.

## 📖 사용법

### 1. 봇 초대하기

먼저 디스코드 서버에 봇을 초대하고, 알림을 보낼 채널에 권한을 주어야 합니다.

1. [봇 초대 링크](https://chzzk.junah.dev/invite/)를 엽니다.
2. 봇을 추가할 **서버를 고르고** `계속하기`를 누릅니다. 관리자 권한이 있는 서버만 목록에 나옵니다.
3. 요청하는 권한(채널 보기, 메시지 보내기 등)을 확인하고 `승인`을 누르면 초대가 끝납니다.

> [!WARNING]
> **채널 권한도 꼭 확인해 주세요.**
> 봇이 서버에 들어와 있어도, 알림을 보낼 채널에 권한이 없으면 알림이 가지 않습니다. 비공개 채널이나 권한을 따로 설정한 채널이라면 `채널 편집` > `권한`에서 치직 봇에게 다음 권한을 **허용**해 주세요.
> * 채널 보기 / 메시지 보내기
> * 링크 첨부 / 파일 첨부
> * 외부 이모지 사용
> * @everyone, @here, 모든 역할 멘션하기 (멘션을 쓸 때만)

### 2. 알림 등록하기

1. [치직 대시보드](https://chzzk.junah.dev)에 디스코드 계정으로 로그인합니다.
2. **내 서버** 목록에서 알림을 등록할 서버를 누릅니다. 서버가 많다면 검색창에서 이름으로 찾을 수 있습니다.
3. **치지직 ID**를 입력하고 알림을 받을 **디스코드 채널**을 고릅니다. 미리보기에서 알림이 어떻게 보일지 바로 확인할 수 있습니다.
4. `알림 추가`를 눌러 저장합니다.
5. 알림 목록에서 `테스트 알림 보내기`를 누르고, 디스코드 채널에 메시지가 오는지 확인합니다.

> [!TIP]
> 서버가 목록에 안 보인다면, 그 서버의 관리자 권한이 있는지 확인해 주세요. 대시보드에는 관리자 권한이 있는 서버만 나옵니다.

> [!WARNING]
> **닉네임이 아니라 채널 ID를 입력해 주세요.**
> 치지직 ID는 채널 주소 **맨 끝의 영문·숫자 문자열**입니다.
> * ❌ 잘못된 예: `김치직`, `kimchzzk`
> * ✅ 올바른 예: `bb382c2c0cc9fa7c86ab3b037fb5799c`
> * *(주소 예시: `https://chzzk.naver.com/live/bb382c2c0cc9fa7c86ab3b037fb5799c`)*

### 3. 메시지 꾸미기

알림 메시지에 멘션을 넣거나, 디스코드 마크다운으로 글자를 꾸밀 수 있습니다. ([자세히 보기](https://chzzk.junah.dev/docs/customization))

#### 멘션

| 대상               | 입력 방법    | 설명                                               |
| ------------------ | ------------ | -------------------------------------------------- |
| **전체**           | `@everyone`  | 서버의 모든 사람에게 알림                          |
| **접속 중인 사람** | `@here`      | 지금 온라인인 사람에게 알림                        |
| **특정 유저**      | `<@유저ID>`  | 한 사람에게만 알림 (예: `<@123456789>`)            |
| **특정 역할**      | `<@&역할ID>` | 그 역할을 가진 사람에게 알림 (예: `<@&987654321>`) |

> [!WARNING]
> **역할을 멘션할 때는 ID 앞에 `&`를 붙여 주세요.**
> `&`가 없으면 유저 멘션으로 인식되어 멘션이 되지 않습니다.
> * ❌ `<@987654321>`
> * ✅ `<@&987654321>`

> [!TIP]
> 유저·역할 ID를 찾으려면 디스코드 `설정` > `고급`에서 `개발자 모드`를 켜고, 유저나 역할을 우클릭한 뒤 `ID 복사하기`를 누르세요.

## ❓ 자주 묻는 질문 (FAQ)

화면에 뜬 오류 메시지와 같은 제목을 찾아보세요. [문제 해결 문서](https://chzzk.junah.dev/docs/troubleshooting/)에서도 볼 수 있습니다.

### 알림을 등록할 때

**Q. 해당 치지직 채널을 찾을 수 없습니다.**

> * 치지직 ID를 잘못 입력했을 가능성이 큽니다. 채널 주소 맨 끝의 **영문·숫자로 된 ID**가 맞는지 확인해 주세요.
> * 한 번도 방송을 켜지 않은 채널은 등록할 수 없습니다.
> * 마지막 방송이 너무 오래된 채널은 치지직에서 정보를 가져오지 못해 등록되지 않을 수 있습니다.

**Q. 이미 해당 디스코드 채널에 등록된 치지직 채널입니다.**

> * 같은 디스코드 채널에 같은 치지직 채널을 두 번 등록할 수 없습니다.
> * 설정을 바꾸려면 기존 알림의 `수정` 버튼을 눌러 주세요.

**Q. 봇이 해당 디스코드 채널에 접근할 권한이 없습니다.**

> * 디스코드 채널이 삭제되었거나, 봇에게 그 채널의 **채널 보기 / 메시지 보내기** 권한이 없는 경우입니다.
> * 위 [봇 초대하기](#1-봇-초대하기)의 채널 권한을 확인하거나, 봇을 서버에 다시 초대해 주세요.

**Q. 알림 등록 제한을 초과했습니다.**

> * 서버의 알림 슬롯을 모두 쓴 경우입니다. 무료로는 5개까지 등록할 수 있습니다.
> * 쓰지 않는 알림을 삭제하거나, [요금제](https://chzzk.junah.dev/pricing)를 확인해 슬롯을 늘려 주세요.

**Q. 서비스 내부 계정이 해당 치지직 채널에서 차단되어 알림을 설정할 수 없습니다.**

> * 치직은 내부 네이버 계정으로 치지직 채널을 팔로우해 방송 여부를 확인합니다. 이 계정이 채널에서 활동 제한(차단)되면 알림을 등록할 수 없습니다.
> * 채널 관리자(스트리머/매니저)에게 차단 해제를 요청해 주세요.

**Q. 현재 서비스 계정의 팔로우 한도가 초과되어 등록할 수 없습니다.**

> * 방송 확인에 쓰는 내부 계정이 팔로우할 수 있는 채널 수를 모두 쓴 경우입니다. 직접 해결할 수 있는 문제가 아닙니다.
> * 오류 메시지 끝의 번호와 함께 서포트 서버로 알려 주시면 관리자가 조치합니다.

**Q. 치지직 채널 팔로우 처리에 실패했습니다.**

> * 일시적인 서버 오류일 수 있습니다. 잠시 후 다시 시도해 주세요.
> * 계속 실패하면 오류 메시지 끝의 번호(예: `(2)`)와 함께 서포트 서버로 문의해 주세요.

**Q. 커스텀 웹훅(커스텀 임베드 색상)은 활성 월간 정기 구독 서버에서만 사용할 수 있습니다.**

> * 커스텀 웹훅과 임베드 색상은 구독자 전용 기능입니다. 서버의 정기 구독이 유지되고 있는지 확인해 주세요.
> * 웹훅 URL은 `https://discord.com/api/webhooks/...` 형식이어야 합니다. 임베드 색상은 `#5865F2`처럼 `#`과 6자리 16진수로 쓰거나, `5793266`처럼 0~16777215 사이의 숫자로 입력해 주세요.

### 알림이 오지 않을 때

**Q. 테스트 알림 전송에 실패했습니다.**

> * 봇이 그 채널에 메시지를 보낼 권한이 없는 경우입니다.
> * 위 [봇 초대하기](#1-봇-초대하기)의 채널 권한을 보고 **채널 보기 / 메시지 보내기 / 링크 첨부** 권한이 허용되어 있는지 확인해 주세요.
> * 커스텀 웹훅을 쓰고 있다면, 웹훅이 삭제되지 않았는지와 URL이 올바른지 확인해 주세요.

**Q. 해당 디스코드 채널이 존재하지 않습니다.**

> * 디스코드 채널이 삭제되었거나, 치직 봇이 서버에서 추방된 경우입니다.
> * 봇을 다시 초대하거나, 알림을 받을 채널을 다시 골라 주세요.

**Q. 방송을 켰는데 알림이 늦게 오거나 오지 않아요.**

> * 방송 상태를 5분마다 확인하기 때문에, 방송을 켜고 알림이 오기까지 최대 5분 정도 걸릴 수 있습니다.
> * 다음 확인 전에 방송을 끄면 봇이 그 방송을 감지하지 못해 **알림이 가지 않습니다.** 방송 테스트처럼 잠깐 켰다 끈 경우가 여기에 해당합니다.
> * 대시보드에서 **테스트 알림**을 보내 권한과 채널 설정이 올바른지 먼저 확인해 주세요.

## 🛠 기술 스택 및 구조

백엔드는 **Serverless Framework**로 배포하는 **AWS Lambda**(Python)와 **DynamoDB**, 프론트엔드는 **Next.js**를 S3 + CloudFront로 배포합니다.

### 동작 방식

1. 대시보드에서 알림을 등록하면, 봇이 관리하는 네이버 계정 중 하나로 그 치지직 채널을 **팔로우**합니다.
2. 5분마다 각 계정의 팔로잉 목록을 조회해 **방송 중인 채널**을 찾습니다.
3. 새로 방송을 시작한 채널이 있으면, 등록된 디스코드 채널(또는 커스텀 웹훅)로 알림을 보냅니다.

채널마다 방송 상태를 따로 조회하지 않고 팔로잉 목록을 한 번에 확인하므로, 등록된 채널이 늘어나도 적은 비용으로 알림을 보낼 수 있습니다. 설계 과정은 아래 개발 비하인드 글에 정리해 두었습니다.

### 폴더 구조

```text
📦
 ┣ 📂 frontend : 대시보드 웹사이트 (Next.js)
 ┣ 📂 lambdas
 ┃ ┣ 📂 api : 대시보드용 REST API (API Gateway)
 ┃ ┃ ┣ 📂 auth : 디스코드 OAuth2 로그인, 내 정보 조회
 ┃ ┃ ┣ 📂 guilds : 디스코드 서버 및 채널 목록 조회
 ┃ ┃ ┗ 📂 notifications : 알림 추가/조회/수정/삭제, 테스트 알림 전송
 ┃ ┣ 📂 bot : 디스코드 인터랙션(슬래시 명령어, 버튼) 처리 (일반 봇 / 관리자 봇)
 ┃ ┣ 📂 cron : 주기적으로 실행되는 작업
 ┃ ┃ ┣ 📂 live_check : 5분마다 방송 상태를 확인하고 알림 전송
 ┃ ┃ ┣ 📂 naver_session_renew : 12시간마다 네이버 세션 갱신
 ┃ ┃ ┣ 📂 sync_koreanbots_stats : 12시간마다 한디리(KoreanBots) 통계 동기화
 ┃ ┃ ┣ 📂 cleanup_orphan_chzzk_channels : 매월 알림이 없는 치지직 채널 정리
 ┃ ┃ ┗ 📂 weekly_report : 매주 통계 리포트 전송
 ┃ ┣ 📂 admin : 관리자가 직접 실행하는 작업 (치지직 채널 팔로우 해제 등)
 ┃ ┣ 📂 shared : Lambda 함수들이 함께 쓰는 공통 코드
 ┃ ┗ 📂 tests : pytest 테스트 (lambdas 구조와 동일)
 ┣ 📂 scripts : 개발용 스크립트 (코드 포맷팅 등)
 ┗ 📜 serverless.yml : AWS 인프라(Lambda, API Gateway, CloudFront 등) 설정
```
