# 치직

<img width="1344" height="756" alt="image" src="https://github.com/user-attachments/assets/5094ed5f-cc37-487f-b156-60da365a3e72" />

**치직**은 [치지직(CHZZK)](https://chzzk.naver.com)에서 스트리머가 방송을 시작하면, 그 소식을 **디스코드 서버로 자동 전달**해 주는 방송 알림 봇입니다.

스트리머 본인은 물론, 팬 커뮤니티 서버 운영자도 봇을 초대하고 치지직 채널을 등록하기만 하면 방송이 켜질 때마다 원하는 디스코드 채널에 알림이 전송됩니다.

- **대시보드**: [chzzk.junah.dev](https://chzzk.junah.dev)
- **문서**: [chzzk.junah.dev/docs](https://chzzk.junah.dev/docs)
- **서포트 서버**: [chzzk.junah.dev/support-server](https://chzzk.junah.dev/support-server)

## 🚀 주요 기능

### 기본 기능 (무료)

* **실시간 방송 알림**: 치지직에서 방송이 켜지면 최대 5분 이내로 디스코드 채널에 알림이 전송됩니다.
* **간편한 대시보드**: 웹 대시보드에서 디스코드 계정으로 로그인해 알림을 추가·수정·삭제하고, 테스트 알림도 보내볼 수 있습니다.
* **커스텀 메시지**: 멘션(@everyone, @here, 특정 유저·역할) 및 디스코드 마크다운을 지원합니다.
* **여러 채널 등록**: 한 서버에서 여러 치지직 채널을 각각 원하는 디스코드 채널로 받아볼 수 있습니다. (무료 플랜 기준 슬롯 5개)

### 구독자 전용 기능 (월 정기 구독)

* **커스텀 웹훅**: 치직 봇의 기본 이름·프로필 대신, 원하는 **이름과 프로필 이미지**로 알림을 보낼 수 있습니다. 디스코드 채널별로 웹훅을 따로 설정할 수 있습니다. ([사용법](https://chzzk.junah.dev/docs/custom-webhook))
* **커스텀 임베드 컬러**: 알림 임베드의 색상을 서버 분위기에 맞게 바꿀 수 있습니다.
* **고급 필터링** *(지원 예정)*: 조건에 따라 알림을 골라서 받을 수 있는 기능을 준비하고 있습니다.
* **빠른 알림 전송**: 구독 서버의 알림이 우선적으로 전송됩니다.
* **슬롯 250개**: 대규모 서버에서도 넉넉하게 알림을 등록할 수 있습니다.

> [!NOTE]
> 구독이 만료되거나 해지되어도 웹훅 등 설정 데이터는 그대로 보존되며, 그동안은 기본 봇 알림 방식으로 전송됩니다.

## 📖 사용법 (User Guide)

### 1. 시작하기 (봇 설치)

치직 서비스를 이용하기 위해서는 먼저 디스코드 서버에 봇을 초대하고 권한을 설정해야 합니다.

1. [이 링크](https://chzzk.junah.dev/invite/)를 클릭하여 봇을 초대합니다.
2. 봇을 추가할 **서버를 선택**하고 `계속하기`를 누릅니다.
3. 필수 권한(채널 보기, 메시지 보내기 등)을 확인하고 `승인`하면 초대가 완료됩니다.

> [!WARNING]
> **봇을 초대했다고 끝이 아닙니다!**
> 봇이 서버에 들어와 있어도, **알림을 보낼 채널에 '메시지 보내기' 권한**이 없으면 알림이 전송되지 않습니다.
> 반드시 해당 채널 설정(`채널 편집` > `권한`)에서 치직 봇의 다음 권한을 **허용**해주세요:
> * **채널 보기**
> * **메시지 보내기**
> * **링크 첨부 / 파일 첨부**
> * **@everyone, @here, 모든 역할 멘션하기** (멘션을 사용하는 경우)

### 2. 알림 등록하기

1. [치직 대시보드](https://chzzk.junah.dev)에 접속하여 디스코드 계정으로 로그인합니다.
2. 관리자 권한이 있는 서버를 선택하고 `대시보드` 버튼을 누릅니다.
3. **치지직 채널 ID**를 입력하고 알림을 받을 **디스코드 채널**을 선택합니다.
4. `추가하기` 버튼을 눌러 설정을 저장합니다.
5. `테스트 알림`을 보내 알림이 정상적으로 도착하는지 확인합니다.

> [!WARNING]
> **치지직 닉네임을 입력하지 마세요!**
> 치지직 채널 ID는 스트리머의 닉네임이 아닙니다. 채널 URL의 **맨 마지막 부분에 있는 고유 ID**를 입력해야 합니다.
> * ❌ 잘못된 예: `김치직`, `kimchzzk`
> * ✅ 올바른 예: `bb382c2c0cc9fa7c86ab3b037fb5799c`
> * *(URL 예시: `https://chzzk.naver.com/live/bb382c2c0cc9fa7c86ab3b037fb5799c`)*

### 3. 메시지 커스텀 (멘션 및 꾸미기)

방송 알림 메시지에 전체 멘션, 특정 유저·역할 호출, 디스코드 마크다운을 이용한 텍스트 꾸미기를 적용할 수 있습니다.

#### 멘션 기능

| 대상 | 입력 방법 | 설명 |
| --- | --- | --- |
| **전체 멘션** | `@everyone` | 서버의 모든 사람에게 알림 |
| **현재 접속자** | `@here` | 현재 온라인인 사람에게 알림 |
| **특정 유저** | `<@유저ID>` | 특정 유저만 콕 집어 알림 (예: `<@123456789>`) |
| **특정 역할** | `<@&역할ID>` | 특정 역할을 가진 그룹 알림 (예: `<@&987654321>`) |

> [!WARNING]
> **역할 멘션 시 문법 주의**
> 특정 역할을 멘션할 때는 반드시 ID 앞에 **`&` (앰퍼샌드)** 기호가 포함되어야 합니다.
> * ❌ 작동 안 함: `<@987654321>` (유저 멘션으로 인식됨)
> * ✅ 정상 작동: `<@&987654321>`

> [!TIP]
> 유저·역할 ID는 디스코드 `설정` > `고급` > `개발자 모드`를 켠 뒤, 유저나 역할을 우클릭하여 `ID 복사하기`로 확인할 수 있습니다.

## ❓ 자주 묻는 질문 (FAQ) & 문제 해결

알림 추가나 전송 과정에서 자주 발생하는 오류 메시지와 해결 방법입니다. 웹사이트의 [문제 해결 문서](https://chzzk.junah.dev/docs/troubleshooting/)에서도 확인할 수 있습니다.

### 알림 등록 시 발생하는 오류

**Q. 400 해당 치지직 채널을 찾을 수 없습니다.**

> * 치지직 ID를 잘못 입력했을 가능성이 큽니다. 채널 URL의 맨 뒷부분이 정확한지 확인해주세요. 닉네임이 아니라 **영문/숫자로 된 고유 ID**여야 합니다.
> * 한 번도 방송을 켜지 않은 채널은 등록할 수 없습니다.
> * 너무 오래 전에 방송을 켰던 채널은 치지직에서 채널 정보를 가져올 수 없어 등록이 불가능할 수 있습니다.

**Q. 400 이미 해당 디스코드 채널에 등록된 치지직 채널입니다.**

> * 한 디스코드 채널에 동일한 치지직 방송 알림을 중복해서 등록할 수 없습니다.
> * 설정을 바꾸고 싶다면 기존 알림의 `수정` 버튼을 이용해주세요.

**Q. 400 알림 등록 제한을 초과했습니다.**

> * 서버에서 사용할 수 있는 슬롯을 모두 사용한 경우입니다. (무료 플랜 기준 5개)
> * 사용하지 않는 알림을 삭제하거나, [요금제](https://chzzk.junah.dev/pricing)를 확인해 슬롯을 늘려주세요.

**Q. 400 서비스 내부 계정이 해당 치지직 채널에서 차단되어 알림을 설정할 수 없습니다.**

> * 치직은 내부 네이버 계정으로 치지직 채널을 팔로우하여 방송 여부를 확인합니다. 이 계정이 해당 채널에서 활동 제한(차단)을 당하면 알림을 등록할 수 없습니다.
> * 채널 관리자(스트리머/매니저)에게 차단 해제를 요청해주세요.

**Q. 500 치지직 채널 팔로우에 실패했습니다.**

> * 일시적인 서버 오류일 수 있습니다. 잠시 후 다시 시도해주세요.
> * 해당 치지직 채널에서 치직 봇을 차단하지는 않았는지 확인해주세요.
> * 계속 실패한다면 오류 메시지 끝의 번호(예: `(2)`)와 함께 서포트 서버로 문의해주세요.

**Q. 400 커스텀 웹훅(또는 커스텀 임베드 색상)은 활성 월간 정기 구독 서버에서만 사용할 수 있습니다.**

> * 커스텀 웹훅과 임베드 색상은 구독자 전용 기능입니다. 서버의 정기 구독이 활성화되어 있는지 확인해주세요.
> * 웹훅 URL은 `https://discord.com/api/webhooks/...` 형식이어야 하며, 임베드 색상은 `#RRGGBB` 형식으로 입력해주세요.

### 알림 전송 관련 오류

**Q. 500 테스트 알림 전송에 실패했습니다.**

> * 치직 봇이 해당 디스코드 채널에 메시지를 보낼 권한이 없는 경우입니다.
> * 위 [시작하기](https://chzzk.junah.dev/docs/installation/)의 권한 설정을 참고하여 **채널 보기 / 메시지 보내기 / 링크 첨부** 권한을 허용했는지 확인해주세요.
> * 커스텀 웹훅을 사용 중이라면, 웹훅이 삭제되지 않았는지와 URL이 올바른지 확인해주세요.

**Q. 404 해당 디스코드 채널이 존재하지 않습니다.**

> * 디스코드 채널이 삭제되었거나, 치직 봇이 해당 서버에서 추방된 경우입니다.
> * 봇을 다시 초대하거나, 알림을 받을 채널을 다시 설정해주세요.

**Q. 방송을 켰는데 알림이 늦게 오거나 오지 않아요.**

> * 방송 상태는 약 5분 간격으로 확인하기 때문에, 방송 시작 후 알림까지 최대 5분 정도 걸릴 수 있습니다.
> * 방송을 켰다가 다음 확인 시점이 오기 전에 꺼버리면, 봇은 그 방송을 감지하지 못해 **알림이 전송되지 않습니다.** 방송 테스트 등으로 잠깐 켰다 끈 경우에는 알림이 가지 않을 수 있습니다.
> * 대시보드에서 **테스트 알림**을 보내 권한과 채널 설정이 올바른지 먼저 확인해주세요.

## 🛠 기술 스택 및 구조

이 프로젝트는 **Serverless Framework**를 기반으로 한 **AWS Lambda**와 **DynamoDB**를 사용하고 있으며, 프론트엔드는 **Next.js**로 구축되어 S3 + CloudFront로 배포됩니다.

### 동작 방식

1. 대시보드에서 알림을 등록하면, 해당 치지직 채널을 봇이 관리하는 네이버 계정 중 하나로 **팔로우**합니다.
2. 5분마다 각 계정의 팔로잉 목록을 조회해 **방송 중인 채널**을 찾습니다.
3. 새로 방송을 시작한 채널이 있으면, 등록된 디스코드 채널(또는 커스텀 웹훅)로 알림을 전송합니다.

채널마다 방송 상태를 하나씩 조회하지 않고 팔로잉 목록을 한 번에 확인하기 때문에, 등록된 채널 수가 늘어나도 적은 비용으로 빠르게 알림을 보낼 수 있습니다. 자세한 고민 과정은 아래 개발 비하인드 글에서 확인할 수 있습니다.

### 폴더 구조

```text
📦
 ┣ 📂 frontend : 치직 봇 대시보드 웹사이트 코드입니다. (Next.js)
 ┣ 📂 lambdas
 ┃ ┣ 📂 api : 대시보드용 REST API (API Gateway)
 ┃ ┃ ┣ 📂 auth : 디스코드 OAuth2 로그인, 내 정보 조회
 ┃ ┃ ┣ 📂 guilds : 디스코드 서버 및 채널 목록 조회
 ┃ ┃ ┗ 📂 notifications : 알림 추가/조회/수정/삭제, 테스트 알림 전송
 ┃ ┣ 📂 bot : 디스코드 인터랙션(슬래시 명령어, 버튼) 처리 (일반 봇 / 관리자 봇)
 ┃ ┣ 📂 cron : 주기적으로 실행되는 작업
 ┃ ┃ ┣ 📂 live_check : 5분마다 방송 상태를 확인하고 알림 전송
 ┃ ┃ ┣ 📂 naver_session_renew : 12시간마다 네이버 세션 갱신
 ┃ ┃ ┣ 📂 sync_koreanbots_stats : 12시간마다 한디리(KoreanBots) 통계 동기화
 ┃ ┃ ┣ 📂 cleanup_orphan_chzzk_channels : 매월 알림이 없는 치지직 채널 정리
 ┃ ┃ ┗ 📂 weekly_report : 매주 통계 리포트 전송
 ┃ ┣ 📂 admin : 관리자가 수동으로 실행하는 작업 (치지직 채널 팔로우 해제 등)
 ┃ ┗ 📂 shared : Lambda 함수 간 공유되는 공통 코드 및 유틸리티
 ┣ 📂 scripts : 개발용 스크립트 (코드 포맷팅 등)
 ┗ 📜 serverless.yml : AWS 인프라(Lambda, API Gateway, CloudFront 등) 설정 파일
```
